# CS50P Harvard Course Practice Repository

This repository contains a complete practice structure for **Harvard CS50P: Introduction to Programming with Python**.  
Each directory maps to a major course topic and includes representative `.py` exercises commonly practiced throughout CS50P.

## Course Topic Structure

- `functions_variables/` – string manipulation, numeric conversion, and simple function composition.
  - `indoor.py`, `einstein.py`, `tip.py`
- `conditionals/` – branching logic and classification problems.
  - `deep.py`, `bank.py`, `extensions.py`
- `loops/` – iteration, input loops, and validation logic.
  - `camel.py`, `coke.py`, `nutrition.py`, `twttr.py`, `plates.py`
- `exceptions/` – robust input handling with `try`/`except`.
  - `fuel.py`, `outdated.py`
- `libraries/` – third-party and standard-library usage.
  - `adieu.py`, `emojize.py`, `game.py`
- `unit_tests/` – CS50P-style test-driven practice with `pytest` conventions.
  - `test_bank.py`, `test_twttr.py`, `test_plates.py`
- `file_io/` – reading/writing CSV and file-processing tasks.
  - `lines.py`, `scourgify.py`, `pizza.py`
- `regex/` – pattern matching and text parsing.
  - `numb3rs.py`, `um.py`, `watch.py`
- `oop/` – classes, encapsulation, and object behavior.
  - `jar.py`, `shirt.py`, `seasons.py`
- `et_cetera/` – extra practice and final-project-oriented experimentation.
  - `final_project.py`, `practice_notes.py`

## How This Connects to CS50P

The layout follows the flow of the course:
1. Build programming fundamentals with variables, expressions, and functions.
2. Add decision-making through conditionals.
3. Improve control flow with loops.
4. Handle invalid input safely with exceptions.
5. Apply Python libraries for practical tasks.
6. Validate behavior with unit tests.
7. Work with persistent data through file I/O.
8. Parse structured text using regex.
9. Design reusable systems with object-oriented programming.
10. Extend skills in open-ended projects.

## Personal Focus: Automation and Robotics

My main goal is to apply CS50P skills to **automation and robotics** work:
- writing scripts that reduce repetitive manual tasks,
- parsing logs and sensor outputs automatically,
- validating robot data pipelines with tests,
- designing clean OOP models for devices, subsystems, and actions,
- preparing for larger robotics software projects where reliability and maintainability matter.

This repo is intentionally organized as a long-term practice base for building that automation-first, robotics-ready Python foundation.
