## Course Coverage by Topic

### 1) Functions & Variables
Focuses on how to accept input, normalize data, and package logic in reusable functions.

### 2) Conditionals
Builds reasoning with branching decisions and structured outcomes based on user input.

### 3) Loops
Develops repetition-based problem solving, including counters, sentinels, and iterative transformation.

### 4) Exceptions
Teaches resilient programs that continue operating gracefully when input is malformed.

### 5) Libraries
Introduces ecosystem leverage: using existing tools (`emoji`, `pyfiglet`, `inflect`, etc.) instead of reinventing functionality.

### 6) Unit Tests
Applies test-driven habits with `pytest`, emphasizing pure functions and edge-case checking.

### 7) File I/O
Covers text and CSV workflows, structured reading/writing, and command-line data handling.

### 8) Regular Expressions
Strengthens validation and parsing with precise matching rules.

### 9) OOP
Explores abstraction through classes, properties, and stateful methods.

### 10) Et Cetera
Integrates prior topics into larger, practical scripts and mini applications.

## My Focus: Automation and Robotics

My goal with CS50P is not only to learn Python syntax, but to build a strong base for automation and robotics engineering. The same skills practiced in these exercises map directly to robotics workflows:

- **Input validation and safety checks** for sensor data and control commands.
- **Loop logic** for repeated polling, control cycles, and event handling.
- **Exception handling** for fault-tolerant robot behavior.
- **File and data processing** for logs, telemetry, and experiment tracking.
- **Testing discipline** to verify motion logic and reduce runtime failures.
- **Library usage** to accelerate integration with external tools and hardware APIs.

This structure is designed to support consistent practice, clearer progression, and long-term transfer from CS50P exercises to real automation systems.
